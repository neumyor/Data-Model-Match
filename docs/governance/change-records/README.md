# Change Record Directory

This directory is the only permitted repository location for machine-readable
contract-change records. Each record must be a JSON file named
`CR-<UPPERCASE-ID>.json` and conform to
`docs/governance/change-record.schema.json`.

No record has been approved for the candidate baseline. A proposed, approved,
or implemented change record is evidence for a governed change; it does not
itself change a frozen contract or waive re-acceptance.
